 
 
 
 
 ## Overview

This project focuses on comparing the effectiveness of humidity sensors, capacitive sensors, and artificial vision cameras for classifying organic and inorganic waste. The system was designed to automate the detection and classification process through different sensing methods, allowing the analysis of accuracy, efficiency, and reliability in waste identification.

## Features
* Humidity Sensor Detection: Identifies waste based on moisture levels commonly found in organic materials.
* Capacitive Sensor Classification: Detects differences in material properties using capacitive sensing technology.
* Artificial Vision System: Uses a camera with image processing techniques to classify waste objects visually.
* Data Comparison and Analysis: Evaluates and compares the performance of each method in terms of accuracy and response time.
* Automated Waste Classification: Demonstrates a prototype capable of assisting in intelligent waste separation processes.
